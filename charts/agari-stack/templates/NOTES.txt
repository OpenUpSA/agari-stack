The migration Job is created together with the release - the web and worker pods
wait for the schema in an init container - so `helm install --wait` only returns
once the schema is in place:
  helm status {{ .Release.Name }} -n {{ .Release.Namespace }}
  kubectl -n {{ .Release.Namespace }} get pods,jobs
  kubectl -n {{ .Release.Namespace }} logs -l app.kubernetes.io/component=migrate --tail=50
